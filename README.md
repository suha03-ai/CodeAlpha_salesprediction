# Sales Prediction - California Housing Dataset

## 📌 Project Overview
This project predicts California house prices using Machine Learning.

## 📊 Dataset
- Source: CodeAlpha / sklearn California Housing
- 20640 samples, 8 features
- Target: MedHouseVal (Median House Value)

## 🛠️ Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib

## 🤖 Models Tried
| Model | R2 Score |
|-------|----------|
| Linear Regression | 0.51 |
| Random Forest | **0.73** |
